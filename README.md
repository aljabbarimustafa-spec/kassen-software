# QuickServe POS

Eine einfache Kassen-Software für Restaurant und Dönerladen.

## Funktionen
- Produktkatalog mit Kategorien
- Warenkorb für Bestellungen
- Rabatt und Zahlungsart
- Verkaufsabschluss mit Rechnung
- Tagesübersicht und Umsatzstatistik
- Lagerbestand mit Warnungen
- Produktverwaltung im Adminbereich
- Speicherung lokal im Browser (localStorage)

## Starten
1. Die Dateien in einem Ordner speichern.
2. `index.html` im Browser öffnen.
3. Anwendung verwenden.

## Beispielbereiche
- Döner, Burger, Pizza, Salat, Getränke, Snacks
- Mitnahme, Lieferung, Im Laden
- Bar, Karte, PayPal, Rechnung

## Hinweis
Dieses ist eine MVP-Version für den Betrieb im lokalen Browser. Für eine echte Restaurant- oder Döner-Kasse mit mehreren Benutzern und Datenbank ist eine Server-/Backend-Umsetzung sinnvoll.
